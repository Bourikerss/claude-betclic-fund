## Synthèse du mois

```dataviewjs
const mois = dv.current().mois;
const bets = dv.pages('"02 - Paris Détectés"')
  .where(p => p.type === "pari" && p.date && String(p.date.toFormat ? p.date.toFormat("yyyy-MM") : p.date).startsWith(mois));
const settled = bets.where(p => ["GAGNE", "PERDU", "REMBOURSE"].includes(p.statut));
const won = settled.where(p => p.statut === "GAGNE").length;
const lost = settled.where(p => p.statut === "PERDU").length;
const staked = settled.where(p => p.statut !== "REMBOURSE").array()
  .reduce((s, p) => s + Number(p.mise_reelle ?? p.mise_recommandee ?? 0), 0);
const profit = settled.array().reduce((s, p) => s + Number(p.profit ?? 0), 0);
const evAvg = bets.length ? bets.array().reduce((s, p) => s + Number(p.ev_percent ?? 0), 0) / bets.length : 0;
const f = (n) => n.toFixed(2);
dv.table(["Indicateur", "Valeur"], [
  ["Paris détectés", bets.length],
  ["Paris réglés", `${settled.length} (${won} G / ${lost} P)`],
  ["Total misé", `${f(staked)} €`],
  ["Profit", `${profit >= 0 ? "+" : ""}${f(profit)} €`],
  ["ROI", staked ? `${f(profit / staked * 100)} %` : "—"],
  ["EV moyenne attendue", `${f(evAvg)} %`],
]);
```

## Par sport

```dataview
TABLE WITHOUT ID sport AS "Sport", length(rows) AS "Paris", round(sum(rows.profit), 2) AS "Profit €"
FROM "02 - Paris Détectés"
WHERE type = "pari" AND dateformat(date, "yyyy-MM") = this.mois
GROUP BY sport
```

## Tous les paris du mois

```dataview
TABLE WITHOUT ID file.link AS "Pari", date AS "Date", cote_betclic AS "Cote", ev_percent AS "EV %", mise_recommandee AS "Mise €", statut AS "Statut", profit AS "Profit €"
FROM "02 - Paris Détectés"
WHERE type = "pari" AND dateformat(date, "yyyy-MM") = this.mois
SORT date ASC
```
