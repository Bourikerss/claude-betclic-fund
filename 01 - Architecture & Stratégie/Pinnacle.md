# Pinnacle

Bookmaker **de référence** (« sharp ») de la [[Stratégie Analyste Contextuel]].

- Marges faibles (≈ 2–3 % sur les grands marchés) et limites élevées.
- Accepte les parieurs gagnants → ses cotes intègrent l'information des meilleurs parieurs.
- **On ne parie jamais chez Pinnacle** : ses cotes servent uniquement à estimer la probabilité réelle via le [[Dé-vigging Pinnacle]].

Clé The Odds API : `pinnacle` (région `eu`). Comparé à : [[Betclic]].
