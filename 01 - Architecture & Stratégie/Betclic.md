# Betclic

Bookmaker **cible** de la [[Stratégie Analyste Contextuel]] : c'est là que les paris sont placés.

- Bookmaker « soft » agréé ANJ : marges plus élevées que [[Pinnacle]], mais cotes parfois en retard sur le marché → opportunités d'[[Expected Value (EV)]] positive.
- Risque de **limitation de compte** pour les profils gagnants : varier les mises, éviter les montants au centime près (arrondir la mise conseillée par les [[Profils de risque]]).
- Clé The Odds API : `betclic_fr` (région `eu`).

Paris détectés : voir le [[00 - Dashboard]].
